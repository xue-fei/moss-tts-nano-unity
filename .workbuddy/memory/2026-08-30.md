- 发现模型文件位于 `Assets/Models/MOSS-TTS-Nano-ONNX/` 而非 StreamingAssets

  - `moss_audio_tokenizer_decode_full.onnx` (非 `decode_full.onnx`)

### 2. 配置数据模型更新 (MossTtsConfig.cs)
- TtsConfig: NVq=16, AudioPadTokenId=1024, 添加 PadTokenId/ImStartTokenId/ImEndTokenId/AudioCodebookSizes/VocabSize
- TtsModelConfig: 添加 RowWidth=17, HiddenSize=768, GlobalLayers=12, GlobalHeads=12, HeadDim=64, VocabSize=16384
- CodecConfig: NumQuantizers=16, DownsampleRate=3840
- OnnxMetadata: 添加 LocalCachedInputNames, LocalFixedSampledFrameInputNames, LocalFixedSampledFrameOutputNames

### 3. 路径解析修复
- codec_meta 路径从 `../MOSS-Audio-Tokenizer-Nano-ONNX/codec_browser_onnx_meta.json` 修复为直接路径
- MossTtsComponent.LoadModel() 增加多路径搜索（streamingAssetsPath/dataPath/绝对路径）
- OnnxRuntimeEngine 和 OrtCpuRuntime 都增加了 codec_meta 回退路径

### 4. ONNX 推理引擎修复 (OnnxRuntimeEngine.cs)
- Prefill: global_hidden 从 [1, seqLen, hidden_size] 取最后时间步
- Decode: global_hidden 从 [1, 1, hidden_size] 取最后时间步
- LocalDecoder: global_hidden 张量形状从 [hidden_size] 改为 [1, hidden_size]
- LocalGreedyFrame/LocalFixedSampledFrame/LocalCachedStep: global_hidden 张量形状修正
- UpdateStreamingStates: 使用 FirstOrDefault 替代 First 防止空引用
- pastStates 张量形状从 [length] 改为 [1, length]

### 5. Attention Mask 修复
- BuildVoiceCloneRequestRows: attentionMask 从 [[1]] 改为 [[1,1,...,1]]（长度=行数）
- Prefill: 正确处理 attentionMask[0] 数组

### 6. 测试脚本
- MossTtsTest.cs: UI 测试脚本（InputField + Button + Dropdown）
- MossTtsSimpleTest.cs: 简单测试脚本（按 T 键触发）
- MossTtsBatchTest.cs: 批量测试（命令行 batchmode）
- MossTtsSceneSetup.cs: 自动场景设置
